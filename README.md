# 谁在操心｜家庭隐形劳动地图

这是一个不依赖后端的纯前端概念 Demo。家庭成员分别记录自己承担的执行、计划、提醒和协调；双方都提交后，系统才合并视角，并通过劳动冰山、责任链和完整责任包帮助家庭共同调整分工。

## 本地运行

进入项目目录后，用任意静态文件服务器托管 `dist/` 即可。例如：

```bash
python3 -m http.server 4173 --directory dist
```

## 迁移说明

`dist/index.html`、`dist/styles.css` 和 `dist/app.js` 构成完整作品，不需要安装依赖或运行构建命令。如果目标平台只接受纯前端代码，可直接上传或复制这三个文件。

当前 AI 分析过程使用经过设计的演示逻辑和示例数据，所有交互都在浏览器内完成，不会上传家庭记录。
