# 谁在操心｜家庭隐形劳动地图

这是一个不依赖后端的纯前端概念 Demo。用户可以创建家庭空间并生成邀请码或邀请链接；家庭成员从各自的设备加入，只记录自己的执行、计划、提醒和协调。所有人提交后，系统才合并视角，并通过劳动冰山、责任链和完整责任包帮助家庭共同调整分工。

## 本地运行

进入项目目录后，用任意静态文件服务器托管 `dist/` 即可。例如：

```bash
python3 -m http.server 4173 --directory dist
```

## 迁移说明

`dist/index.html`、`dist/styles.css` 和 `dist/app.js` 构成完整作品，不需要安装依赖或运行构建命令。如果目标平台只接受纯前端代码，可直接上传或复制这三个文件。

当前分析由浏览器内的中文规则引擎完成。用户手动输入的内容会真实影响劳动类型、双方占比、冰山任务、认知差异和责任包分配。演示版的邀请码和邀请链接已经包含完整前端流程，但跨设备实时同步需要正式版后端；当前家庭记录只保存在浏览器本地，不会被上传。

冰山插画由 OpenAI 内置 ImageGen 生成，项目内文件位于 `dist/assets/iceberg-gouache.png`。
